# Thrissur Corporation CCMS Project Proposal

This directory contains the official project proposal and technical documentation for the **Thrissur Corporation Citizen Complaint Management System**.

## Key Latest Updates

- **Plan B Architecture**: Multimedia (photos) is now stored as compressed Base64 strings directly in Firestore, bypassing standard Cloud Storage CORS and permission issues.
- **Auto-Rescaling Engine**: Integrated high-performance image manipulation that automatically resizes (1200px) and compresses (0.5 quality) all uploads.
- **Enhanced System Scripts**: Upgraded administrative tools for deep project purging and progress-tracked data seeding.

## Contents

- **Thrissur_Corporation_Citizen_Complaint_Management_System_Project_Proposal.md**: The primary technical document covering architecture, workflows, database design, and role-based functionalities.
- **diagrams/**: Contains system diagrams in Mermaid format.
- **screenshots/**: Organized screenshots of the implemented application modules.
- **assets/**: Supporting visual assets.
